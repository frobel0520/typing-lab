# Typing Lab 原生桌面版

這個資料夾是實際的 Windows 桌面應用程式，不是瀏覽器頁面。

## 直接啟動

若電腦已安裝 Python 3.12，直接雙擊 `TypingLab.pyw`。它會開啟獨立的 800×600 原生視窗，不會開瀏覽器。

也可以在 PowerShell 執行：

```powershell
py -3.12 native/TypingLab.pyw
```

## 目前功能

- 英文 QWERTY 與注音大千鍵位練習
- 中文模式顯示目標中文字句；聲母、介音、韻母可不分順序，聲調必須最後按下
- 15,114 個完整英文句子與 1,659 句繁體中文本機句庫；每輪洗牌後用完才重抽，避免固定內容反覆連續出現
- 中英文各包含 32 句動漫／原神主題的原創改寫練習句
- 無限補充練習內容
- 不計時、不顯示正確率、不設完成畫面
- 錯誤輸入不前進，也不累計錯誤字數
- 英文與中文分開保存累計字數與每日練習字數，右側熱點圖會隨目前模式切換
- 目前按鍵、手指、左右手與虛擬鍵盤提示
- 虛擬鍵盤只顯示按鍵，不在鍵帽上顯示指法文字
- 本機保存模式與鍵帽指法設定

中文模式請先切換至 ENG 英文鍵盤。聲母（ㄅ～ㄙ）、介音（ㄧ～ㄩ）與韻母（ㄚ～ㄥ）可不分順序輸入，同一組後按的鍵會覆蓋前一個鍵；ㄦ 是獨立一組。聲調一定要最後按下：一聲是 Space，其他聲調按各自的聲調鍵，按完即完成。例如 `ㄎㄨㄥˋ` 可按 `D`、`J`、`/`、`4`，順序可調換，但 `4` 必須最後按。畫面一次只反白一個中文字；標點會顯示但自動略過。不需要選字，也不需要 Enter。

英文句庫採用 Tatoeba 英文例句（CC BY 2.0 FR），並加入 `fiction_english_data.py` 的動漫／原神主題原創英文改寫句；中文句庫採用臺灣 TBCL 例句、教育部字典注音欄位，以及 `fiction_data.py` 的 32 句動漫與原神主線風格原創短句整理而成。資料已內嵌，啟動時不需要網路。

## 打包成 exe

若環境有 PyInstaller，可以從專案根目錄執行：

```powershell
py -3.12 -m PyInstaller --noconfirm --clean native/TypingLab.spec
```

輸出會在 `dist/TypingLab.exe`。本次環境已確認有 Python 3.12、Tkinter 與 PyInstaller。
